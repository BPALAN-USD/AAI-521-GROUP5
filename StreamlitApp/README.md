## Driver Distraction Detection – Streamlit App

This project wraps your existing YOLO-based **State Farm Distracted Driver Detection** notebook into an end-to-end **Streamlit** web app.

The app provides a guided workflow:

- **Dataset download from Kaggle** (using the bundled `kaggle.json`, no upload needed)
- **Dataset extraction & train/val/test split** (using `splitfolders`)
- **YOLO classification training** (based on `yolo11n-cls.pt`)
- **Model evaluation** (metrics + confusion matrix/results plots)
- **Image upload & prediction** – detect which distraction class a driver image belongs to

---

## 1. Environment setup

- **Python**: 3.9+ recommended
- **Install dependencies** (from the `DriverDistractionAlgorithm` folder):

```bash
pip install -r requirements.txt
```

> If you prefer, create and activate a virtual environment first (e.g. `python -m venv .venv && source .venv/bin/activate`).

---

## 2. Kaggle credentials (no upload required)

The app uses the existing **Kaggle API token** directly:

- Make sure a valid `kaggle.json` file is present in the same folder as `streamlit_app.py` (this repo already includes your token).
- The app will:
  - Read `kaggle.json`
  - Set `KAGGLE_USERNAME` and `KAGGLE_KEY` environment variables
  - Copy the file to `~/.kaggle/kaggle.json` with proper permissions (600)

There is **no UI upload button** for the token – it is fully automated.

You must also have the Kaggle CLI available:

```bash
pip install kaggle
```

Make sure the `kaggle` command works, for example:

```bash
kaggle competitions list | head
```

---

## 3. Running the Streamlit app

From the `DriverDistractionAlgorithm` directory, run:

```bash
streamlit run streamlit_app.py
```

This will open a browser window (or give you a local URL) for the app.

---

## 4. App workflow

The app is organized into **three tabs at the top** that guide you through the workflow:

### 4.1 Tab 1 – Train model

- **Tab name**: “1. Train model”
- **What it does (in one click)**:
  - Downloads the Kaggle competition dataset
  - Extracts all archives into `statefarm_data/`
  - Creates train/val/test splits with `splitfolders` (70/15/15) under `statefarm_data/output`
  - Trains a YOLO classifier (`yolo11n-cls.pt` backbone) and saves the best weights (`best.pt`) under `runs/statefarm_cls/weights/`
- You can choose the number of training epochs before running the pipeline.

### 4.2 Tab 2 – Evaluate & visualize

- **Tab name**: “2. Evaluate & visualize”
- **Controls**:
  - Text field for the model weights path (defaults to the tracked `best.pt`)
  - **Run evaluation** button to execute `model.val()` and display:
    - JSON metrics (from `metrics.results_dict` when available)
    - `confusion_matrix_normalized.png` (if generated by Ultralytics)
    - `results.png` (training curves and metrics)
  - **Show sample validation predictions** button to:
    - Load a small set of validation images
    - Show each image with its **true label** and **predicted label + confidence**

### 4.3 Tab 3 – Predict from uploaded image

- **Tab name**: “3. Predict from image”
- **Controls**:
  - Text field for the model weights path (defaults to tracked `best.pt`)
  - Image uploader for JPG/PNG
  - **Run prediction** button

Prediction behavior:

- Loads the YOLO classifier from the provided weights path.
- Shows the uploaded image.
- Outputs:
  - **Top-1 predicted class label** with confidence
  - **Top-5 class predictions** with confidence scores (if available)

Classes follow the mapping from your notebook:

```text
0: normal driving
1: texting - right
2: talking on the phone - right
3: texting - left
4: talking on the phone - left
5: operating the radio
6: drinking
7: reaching behind
8: hair and makeup
9: talking to passenger
```

---

## 5. Notes & tips

- **Compute requirements**: Downloading and training on this dataset is heavy (several GB, many images). A GPU is strongly recommended.
- **Idempotent steps**: Downloading, extraction, and splitting all check for existing artifacts and skip work when it’s already done.
- **Customizing training**:
  - You can increase epochs, adjust batch size, etc., by editing `train_model()` in `streamlit_app.py`.
- **Reusing a pre-trained model**:
  - If you already trained a model elsewhere, copy the `best.pt` into this project and point the “Model weights to use for inference” field at it.

---

## 6. Quick start summary

1. `cd` into `DriverDistractionAlgorithm`.
2. `pip install streamlit ultralytics split-folders kaggle pillow`.
3. Ensure `kaggle.json` is present next to `streamlit_app.py`.
4. Run `streamlit run streamlit_app.py`.
5. Use the **top tabs** in order:
   - 1️⃣ **Train model** – runs download → extract → split → train and saves `best.pt`  
   - 2️⃣ **Evaluate & visualize** – see metrics, confusion matrix, and sample validation predictions  
   - 3️⃣ **Predict from image** – upload an image and see the predicted driver distraction class.
